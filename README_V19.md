# Loka V19 — Boutique Neo Flux

V19 ajoute le deuxième template boutique réellement directionnel après Boutique Editorial V18.

## Direction
- contemporain
- graphique
- expressif
- grande typographie
- composition asymétrique
- accent configurable
- collage éditorial
- commerce conservé comme fonction, sans transformer le template en dashboard

## Intégration
`BoutiqueNeoFluxTemplate.tsx` est sélectionné par `StorefrontRenderer` pour `boutique_neo_flux`.

Le catalogue contient désormais ce template comme entrée Business.

## Preview HTML
Le fichier `V19_HTML_PREVIEW_PROMPT.md` contient le prompt destiné à générer une version HTML autonome pour vérification directe sur téléphone.
