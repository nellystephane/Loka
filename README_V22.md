# Loka V22 — Art-Directed Commerce / Pop Object

V22 ajoute le template boutique `boutique_pop_object`.

## Direction

Le produit devient un objet graphique dans une composition de campagne : surfaces colorées, superpositions, produits débordants, typographie XXL et interactions tactiles discrètes.

Cette direction complète les précédentes :
- V18 Editorial
- V19 Neo Flux
- V20 Orbit Glass
- V21 Float Form
- V22 Pop Object

## Intégration

Le template est enregistré dans :
- `client/src/components/storefront/StorefrontRenderer.tsx`
- `client/src/components/storefront/templateCatalog.ts`
- `client/src/components/storefront/BoutiquePopObjectTemplate.tsx`
- `client/src/styles/globals.css`
