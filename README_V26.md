# Loka V26 — Kinetic Atelier

## Boutique storefront template #15

Kinetic Atelier is a modern motion-design storefront for Boutique spaces.

### Direction
- typographic and sequence-driven
- warm paper / black / signal-red palette
- technical grid
- orbital geometry
- animated marquee
- product parallax in the hero
- asymmetric product presentation
- motion study section
- responsive mobile composition
- reduced-motion support

### Integration
- renderer: `client/src/components/storefront/StorefrontRenderer.tsx`
- template: `client/src/components/storefront/BoutiqueKineticAtelierTemplate.tsx`
- catalogue definition: `client/src/components/storefront/templateCatalog.ts`
- quick view theme: `client/src/components/storefront/StorefrontProductQuickView.tsx`
- styles: `client/src/styles/globals.css`

Kinetic Atelier only affects the public Boutique storefront. It does not replace the Loka platform UI design system.
