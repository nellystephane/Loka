# Loka V20 — Boutique Orbit Glass

V20 ajoute le template **Boutique Orbit Glass**.

Direction artistique : spatial commerce / app-like / glass interface.

Le template est inspiré de principes de design observés dans des interfaces de mobilité, e-commerce premium et glassmorphism : média principal dominant, recherche flottante, couches translucides, éléments circulaires, navigation tactile et forte hiérarchie visuelle. Il ne reproduit aucune création précise.

Le template est disponible dans le StorefrontRenderer sous :

`boutique_orbit_glass`

Un prompt autonome pour générer une version HTML mobile est disponible dans :

`V20_HTML_PREVIEW_PROMPT.md`

Le workflow GitHub existant n'est pas modifié.
